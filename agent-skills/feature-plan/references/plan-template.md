# Feature plan template

## Goal and scope

- Requested outcome
- In scope
- Out of scope
- Assumptions grounded in the ticket or repository

## Existing system

- Relevant modules, flows, and nearby patterns
- Constraints from architecture and project conventions

## Proposed design

- Responsibilities and dependency direction
- Interfaces, state, data, and error handling
- Compatibility, migration, rollout, or rollback where relevant

## Change map

- Concrete files or directories grouped by responsibility
- New files distinguished from modifications

## Implementation order

- Dependency-aware slices that can be implemented and verified coherently

## Validation

- Behaviors and failure cases to test
- Repository commands or CI gates to run

## Open decisions and risks

- Only unresolved items that could materially alter the design or delivery
